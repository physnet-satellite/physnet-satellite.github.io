# Physical Networks Satellite Archive

Website and archive for the Physical Networks NetSci satellite series.

**[Visit the website](https://physnet-satellite.github.io/)**

Built with [Quarto](https://quarto.org/). Edit content in `data/`, templates in `templates/`, and images and styles in `assets/`.

With Quarto installed, build and validate locally:

```bash
make install build
```

Use `quarto preview` for a local preview. Commit generated pages with their inputs and push to `main` to publish automatically through GitHub Actions.
